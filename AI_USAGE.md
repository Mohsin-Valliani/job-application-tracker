# AI Usage Documentation

**Student:** Mohsin Valliani
**Course:** COP4751
**Project:** JobTrack — Job Application Tracker

## Tools Used

I used ChatGPT throughout the development of my JobTrack project as a resource for troubleshooting, understanding code, and improving different parts of the application.

It helped me understand Flask, MySQL, database relationships, SQL queries, and form validation. I also used it when I ran into errors and needed help figuring out what was causing them.

## Key Prompts

Some of the things I asked ChatGPT for help with included:

- Explaining how different parts of the Flask application work.
- Troubleshooting MySQL queries and database errors.
- Fixing issues with application forms and status dropdowns.
- Checking JSON formatting and validation.
- Reviewing the application and suggesting additional tests.

## What Worked Well

ChatGPT was helpful when I ran into problems that I wasn't sure how to fix. It helped explain errors and gave me a better understanding of how different parts of the application connect.

It was also useful for going through the application step by step and identifying areas that needed to be checked or improved.

## What I Changed

During development, I reviewed and tested different parts of the application and made changes when issues came up.

Some of the improvements included fixing application status options, updating database status values, improving form behavior, and checking that changes were properly saved in MySQL.

I also made sure the dashboard reflected updates made to application records.

## Lessons Learned

This project helped me better understand how Flask works with MySQL and how database relationships connect different types of records.

I also learned that getting code to run is not enough. It is important to test different situations, check for errors, and make sure changes are actually saved in the database.

Using AI for troubleshooting was helpful, but I still needed to review the suggestions and test them in my own application.
